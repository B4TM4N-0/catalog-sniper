Documentation

Catalog Sniper provides public Roblox catalog data containing emotes, animations, and moods.

All datasets are available as JSON files and are automatically updated through GitHub Actions.

Endpoints

GET /v1/emotedata.json

Returns Roblox emote catalog data.

GET /v1/animationdata.json

Returns Roblox animation catalog data.

GET /v1/mooddata.json

Returns Roblox mood catalog data.

GET /v1/info.json

Returns dataset metadata and statistics.

Response Format

All catalog files use a consistent JSON structure. 

{
  "keyword": null,
  "totalItems": 112,
  "lastUpdate": "2026-07-23T10:25:43.372Z",
  "data": [
    {
      "id": 14618207727,
      "name": "Default Mood"
    }
  ]
}

Examples

Fetch a dataset using a normal HTTP request: 

fetch("/v1/mooddata.json")
  .then(response => response.json())
  .then(data => {
    console.log(data);
  });
