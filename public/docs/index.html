Documentation

Access public Roblox catalog datasets for emotes, animations, and moods via lightweight JSON APIs.

Catalog Sniper provides public Roblox catalog data. All datasets are delivered as standalone JSON files and are automatically synchronized through GitHub Actions.

Endpoints

All endpoints return JSON data and support standard CORS headers.

GET /v1/emotedata.json

Returns Roblox emote catalog data including assets, IDs, and titles.

GET /v1/animationdata.json

Returns Roblox animation catalog data and associated asset details.

GET /v1/mooddata.json

Returns Roblox mood catalog data for avatars.

GET /v1/info.json

Returns dataset metadata, count statistics, and last-synced timestamps.

Response Format

Every catalog query returns a standardized JSON response:

{
  "keyword": null,
  "totalItems": 112,
  "lastUpdate": "2026-07-23T10:25:43.372Z",
  "data": [
    {
      "id": 14618207727,
      "name": "Default Mood"
    }
  ]
}

Examples

Get started with Catalog Sniper using Roblox's built-in HttpService.

Fetch emote data

Retrieve the emote dataset and print the first 10 entries.

example.luau 
local HttpService = game:GetService("HttpService")
local data = HttpService:JSONDecode(HttpService:GetAsync("https://catalog-sniper.vercel.app/v1/emotedata.json"))

for i = 1, math.min(10, #data) do
    local emote = data[i]
    print(emote)
end
i

Note HTTP requests must be enabled in your Roblox experience under Game Settings > Security.
