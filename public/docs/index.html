Documentation

Access public Roblox catalog datasets for emotes, animations, and moods via lightweight JSON APIs.

Catalog Sniper provides high-availability public Roblox catalog data. All datasets are delivered standard as standalone JSON files and are automatically synchronized via GitHub Actions background jobs.

Endpoints

All endpoints respond with standardized HTTP standard payloads and support standard CORS headers.

GET /v1/emotedata.json

Returns Roblox emote catalog data including assets, IDs, and titles.

GET /v1/animationdata.json

Returns Roblox animation catalog data and associated asset details.

GET /v1/mooddata.json

Returns Roblox mood catalog data for avatars.

GET /v1/info.json

Returns overall dataset metadata, global count statistics, and last-synced timestamps.

Response Format

Every catalog query returns a standard structural response payload:

response.json json 
{
  "keyword": null,
  "totalItems": 112,
  "lastUpdate": "2026-07-23T10:25:43.372Z",
  "data": [
    {
      "id": 14618207727,
      "name": "Default Mood"
    }
  ]
}

Examples

Fetch dataset contents using JavaScript's native Fetch API:

example.js javascript 
fetch("/v1/mooddata.json")
  .then(response => response.json())
  .then(data => {
    console.log(data);
  });
