Sniper API

Open-source Roblox emotes, animations, and moods catalog API. Automatically updated using GitHub Actions.

Documentation GitHub

Endpoints

/v1/emotedata.json

Roblox emotes catalog data.

/v1/animationdata.json

Roblox animation catalog data.

/v1/mooddata.json

Roblox moods catalog data.

/v1/info.json

API metadata and statistics.

About

Sniper API provides free JSON data for Roblox catalog assets. Data is collected automatically and updated periodically.

Built with Node.js, GitHub Actions, and Vercel.
